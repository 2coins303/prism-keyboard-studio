openrazer-win 1.6.3 — GPL-2.0-or-later
https://github.com/Ar4ikov/openrazer-win
HID transport and protocol builders, derived from OpenRazer.
The installed version's complete Python package source is in
source/vendor/openrazer_win. No source modifications were made to that package.
Prism selects only vendor 1532, product 02A6 and uses the documented
90-byte control collection on interface 3. It requires status 0x02 responses;
the upstream library's unfinished BUSY responses are not counted as success.

OpenRazer — GPL-2.0-or-later
https://github.com/openrazer/openrazer
02A6 protocol recipes: 6 rows × 22 columns, extended matrix commands,
transaction 0x1F for custom frames/effects/brightness, 0xFF for identity.
Prism uses the verified matching extended brightness read (0F:84); the
upstream standard read is rejected by this connected keyboard firmware.
