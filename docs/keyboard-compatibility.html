Models that need different support

Generic QMK boards and Keychron Q/V/K Pro/Max models are not automatically supported by this managed setup. Only the listed K3 V2 Optical RGB has a specific native detector here; it supports manually applied static colors because the device automatically saves them. Prism never flashes firmware.

Redragon K552/K617, Royal Kludge RK61/RK84 and AULA F75/F99 are not promised. Logitech G512/G513 and newer G Pro X models are not enabled by this restricted managed setup; OpenRGB's generic Logitech detection path can also inspect other Logitech device types. An already configured external OpenRGB server may expose additional keyboards, but these are not part of Prism's managed compatibility promise.

Zone lighting has reduced spatial and stereo detail. An unknown matrix produces a lighting-address list and mirrored audio until you supply a physical map. The program never treats LED list order as physical left-to-right order.

Source baseline: OpenRGB 1.1, released October 16, 2026. Exact detector links appear beside each model. Corresponding source is supplied in source/OpenRGB-1.1-corresponding-source.zip.
